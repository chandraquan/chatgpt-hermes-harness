# Codex task registry template

Copy this file to `REGISTRY.md` when provisioning a new project instance.
`REGISTRY.md` is ignored because it contains machine-local task IDs and live task
state.

## Entry format

```markdown
### Exact task title

- Task ID: when known
- Purpose: one sentence
- Status: active | waiting | blocked | complete | archived
- Owner/lane: main task or delegated responsibility
- Last update: YYYY-MM-DD and concise evidence
- Next handoff: concrete next action, or none
```
