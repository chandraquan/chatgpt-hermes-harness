# Memory index

Load `CORE.md` and `USER.md` at the start of every task. Load the remaining files
only when relevant.

- `CORE.md` — stable project identity, objectives, constraints, and current state.
- `USER.md` — stable user preferences that apply only to this project.
- `DECISIONS.md` — architectural and product decisions with rationale/status.
- `LEARNINGS.md` — reusable lessons from successes, failures, and corrections.
- `OPEN_LOOPS.md` — unresolved work, blockers, and promised follow-ups.

Memory is curated state, not a transcript. Date entries using `YYYY-MM-DD`, cite
their evidence (task, file, command, or explicit user statement), and mark stale
entries as superseded instead of silently contradicting them.
